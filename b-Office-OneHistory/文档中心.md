# OneHistory 公共文档中心

这里是 **跨项目** 的公共文档区，由 HistoryDiana 托管。Diana 自身的项目合同不在这里，在
[`../b-Office-Diana/`](../b-Office-Diana/)。

## 总目录不在本页

跨项目说明书的索引**不是**下面这份手写表格。手维护文件表会漂移。

合法索引只有一条现场扫描命令，而且**必须把完整输出留在当前对话里**，然后再选通道：

```
diana.docs.catalog
```

catalog 按工作树根下每个含 `SHA256SUMS` 的 `z-*` 列出一条通道。多一个 z 文件夹就多一条
`diana.docs.<域>`。省略 `file` 只列出该通道；带 `file=` 才读一篇 Markdown。
不要一次把全部正文读进上下文。

若 catalog 列出了通道但命令尚未登记，执行 `vulcan.module.reload` 让 Diana 按当前 z 重新附着。

编辑源仍在各项目 `b-Office/package/`。已发布正文只在对应 `z-*/docs/`（及该 z 内已登记的 `.md` / `.txt`）。
AI 跨项目读取走 MCP 通道，不直接打开别的 worktree，也不从本目录找副本——这里已经没有副本。

运行时命令面另见 [`命令面总览.md`](./命令面总览.md)，那是宿主导出的横切事实，不是消费说明书。

## 读取顺序

1. [`定义/OneHistory总览.md`](./定义/OneHistory总览.md) —— 先搞清楚“项目库 / 宿主 /
   模块 / 工作区 / 消费区”这些词各指什么。
2. [`定义/目录与命名规范.md`](./定义/目录与命名规范.md) —— 目录前缀、编号分支、
   指令命名、版本源的跨项目约定。
3. 执行 `diana.docs.catalog`，把输出留在对话中，再调用其中一个 `diana.docs.<通道>`。
