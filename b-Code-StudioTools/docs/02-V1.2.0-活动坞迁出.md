# V1.2.0 活动坞迁出

> 日期：2026-08-02  
> 状态：源码、构建与 Smoke 完成

## 变更

`dock` 逻辑模块整体迁出为独立物理模块 `ActiveDock 1.0.0`，源码位于 `b-Code-ActiveDock`，注册目录
`z-ActiveDock`。迁出理由与宿主归属见该模块的
`b-Code-ActiveDock/docs/01-V1.0.0-活动坞独立模块.md`。

`StudioTools` 由四逻辑模块降为三个：

| 逻辑模块 | 命令数 | 状态 |
|---|---|---|
| `ProjectPulse` | 3 | 保留 |
| `ToolKit` | 4 | 保留 |
| `ToolRelay` | 3 | 保留 |
| `dock` | 6 | 迁出至 `ActiveDock` |

聚合程序集因此不再含任何 `IUiModule`，清单 `ui` 由 `true` 改为 `false`。三个逻辑模块版本与程序集版本统一
提升到 `1.2.0`。

## 影响

- 命令总数由 16 条降为 10 条，`dock.*` 六条命令改由 `ActiveDock` 提供，命令域和签名不变；
- `ProjectIconGenerator` 随 dock 一并迁出，聚合程序集不再依赖 `System.Windows.Media.Imaging`；
- Smoke 断言相应调整：三个模块入口、版本 `1.2.0`、零个 UI 生命周期，图标回归移入 ActiveDock 的 Smoke；
- 部署时必须先同步 `StudioTools 1.2.0` 再同步 `ActiveDock 1.0.0`，否则 `dock` 命令域冲突。

V1.1.0 的四模块聚合背景见 `01-V1.1.0-四模块聚合迁移.md`。本次迁出不改变其余三个模块的聚合结论。

## 验证

- `dotnet build .\b-Code-StudioTools\StudioTools.csproj -c Release`：0 warning、0 error；
- `dotnet run --project .\b-Code-StudioTools\tests\Smoke\Smoke.csproj -c Release`：
  `StudioTools.Smoke: PASS (3 modules, 10 commands, 0 UI modules)`。
