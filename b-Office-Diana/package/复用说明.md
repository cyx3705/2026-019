# HistoryDiana 文档包复用说明

`package/` 保存派生项目和 AI 可以稳定消费的项目级规则。这里不记录单个项目的阶段进度、临时
问题或实现细节，也不保存发布生成物。

## 消费顺序

1. 先读取根目录 `AGENTS.md` 与 `project.manifest.json`。
2. 读取 `../current/项目概览.md`，确认项目目标和当前里程碑。
3. 根据任务读取 `../current/技术合同.md`、`../current/有效决策.md` 或 `../current/验证合同.md`。
4. 涉及目录新增、拆分时读取 `../文档中心.md` 的“目录规范”；要读其他项目说明书时，直接执行
   `diana.docs.catalog`，把索引留在对话中，再选一条通道。

package 文档应保持稳定、精简且不含项目实例化占位符。项目特有内容必须写入 `../current/`，
过期资料移入 `../history/`。其他模块的已发布正文在各自 `z-*/docs/`，不在 Diana 里保存副本。

## AI 前端图形查看

先执行 `diana.view.windows` 取得当前 HistoryVulcan 前端的窗口句柄，再执行
`diana.view.capture handle=<句柄>`。省略 `handle` 时自动选择客户区面积最大的可见窗口。
结果给出原尺寸 PNG 的绝对路径、SHA-256、采集方式和像素统计；AI 应读取该 PNG 核对布局、文字、
重叠与空白区域。查看器只捕获 `HistoryVulcan.exe`，不读取其他桌面应用；最小化窗口会明确拒绝。
