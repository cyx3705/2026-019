# HistoryDiana 项目概览

更新日期：2026-09-13

## 一句话定义

HistoryDiana 是 OneHistory 的 **AI 工具区**：统一承接面向 AI 的跨项目观察、巡检、读取、转换和工具中继能力。
除 HistoryVulcan 已冻结的模块开发管线外，新增 AI 通用工具默认归 Diana。

## 定位

Mercury 等业务模块继续拥有面向人的交互与各自领域能力；Diana 不复制这些实现，而是为 AI 提供统一的
工具入口、可信文档和可复核观察证据。一个能力若服务于 AI、跨项目且不属于业务领域合同，默认由 Diana 拥有。

Diana 不注册自己的用户界面（`ui: false`），只提供指令与文档入口；图形查看器观察已运行的
HistoryVulcan 前端，不创建窗口或注入控件。

## 目标与边界

### 目标

1. 提供 AI 常用的观察能力：控制台日志读取（`diana.log.read`）、宿主装载观察（`diana.host.*`）、
   前端图形查看（`diana.view.*`）、工作树巡检（`diana.project.*`）、
   小工具（`diana.kit.*`）、MCP 工具中继（`diana.relay.*`）、
   按 z 通道读说明书（`diana.docs.*`）。
2. 作为新增 AI 通用工具的默认归属区，避免同类能力散落在宿主或业务模块。
3. 保留项目合同校验和本模块候选构建辅助脚本（`b-Code/`）；本仓不拥有发布器，写入 z 只由宿主
   `vulcan.dev.submit` / `vulcan.dev.finish` 管理。
4. 通过 `diana.project.manifest/docs/align` 为当前已实现范围内的 Janus、Mercury、Minerva、Vulcan
   提供统一开发对齐入口。

### 边界

- 不提供自己的 UI 页面，不注册窗口，不参与用户日常交互；只捕获同一用户会话中的 HistoryVulcan 前端。
- 不登记 `diana.worktree.*`、`diana.release.*`、`diana.trial.*`。
- 不拥有模块开发管线或发布器。冻结的 `vulcan.dev.start/submit/finish` 只由 HistoryVulcan Console CLI 提供，
  不走 MCP，也不得经 `diana.relay.call` 绕行。
- 不吞并业务模块的领域命令；Diana 只拥有 AI 专用的通用工具与中继入口。
- 消费文档权威源永远在各自仓库的 `b-Office/package/`；已发布正文位于
  `z-Publish/HistoryX-vX.Y.Z/docs/`。跨项目读取必须先执行 `diana.docs.catalog`。
- 写命令恰为 `diana.relay.call` 与 `diana.view.capture`；后者只写 Diana 运行态 PNG。
- `diana.host.*` 只转发宿主自己的只读装载查询，不安装、不重载、不改运行包，也不属于开发管线。
- 模块主线不是 AI 日常编辑区；开发工作区由宿主 `vulcan.dev.*` 管理。Diana 自身也必须走同一管线。

## 主要交付物

| 交付物 | 权威位置 | 完成判据 |
| --- | --- | --- |
| 模块产物 | `z-Publish/HistoryDiana-vX.Y.Z/` | dll + xml + manifest + SHA256SUMS |
| 项目合同 | `b-Office-Diana/current/` | 四份现行合同与计划态需求书边界清楚，未实现能力不得写成现状 |
| 原生控制台日志读取 | `diana.log.read` | 当前前端实例、结构化记录、完整多行错误、增量序号和 256 KiB 边界可复核 |
| 宿主装载观察 | `diana.host.modules` + `diana.host.ready` + `diana.host.observe` | 模块版本、实例 ID、指令数与附着失败可在 MCP 面直接核对 |
| 模块开发观察手册 | `b-Office-Diana/package/模块开发观察手册.md` | 一轮里的三个取证点、症状对照与降级顺序，随包发布到 z |
| 冻结开发管线 | 宿主 `HistoryVulcan.Cli.exe --cli vulcan.dev.*` | 只走 CLI，由用户审查后授权 submit/finish |
| z 文档查看器 | `diana.docs.catalog` + `diana.docs.read domain=<域>` | catalog 文本必须出现在对话中 |
| AI 图形查看器 | `diana.view.windows` + `diana.view.capture` | PNG 尺寸、SHA 和非空像素统计可复核 |

## 依赖

- **HistoryVulcan 宿主**：最低 `5.1.2`；提供模块注册、命令总线和模块开发管线。
- **.NET SDK 9.0.315**，目标框架 `net8.0-windows`。

## 与其他项目的关系

Diana 的巡检与文档指令只读；`relay.call` 是显式写能力。别的项目通过 Diana MCP 使用 AI 通用工具并读取
正式 z 文档通道；模块开发闭环只走宿主 Console CLI。业务模块仍对自己的领域命令负责。
