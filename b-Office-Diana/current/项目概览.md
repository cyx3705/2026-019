# HistoryDiana 项目概览

更新日期：2026-08-22

## 一句话定义

HistoryDiana 是 OneHistory 的 **AI 侧常驻工作区**：提供项目巡检、小工具、MCP 中继和 z 文档通道。
模块开发闭环（工作区、发布、装机）已迁到 HistoryVulcan 宿主。

## 定位

与 HistoryMercury 对称：

- **Mercury 是人的翻译官**：桌面活动坞、全局快捷键、命令工作台。
- **Diana 是 AI 的翻译官**：项目巡检、工具中继和 z 文档通道。

Diana 不进入用户日常界面（`ui: false`），只提供指令与文档入口。

## 目标与边界

### 目标

1. 提供 AI 常用的只读能力：工作树巡检（`diana.project.*`）、
   小工具（`diana.kit.*`）、MCP 工具中继（`diana.relay.*`）、
   按 z 通道读说明书（`diana.docs.*`）。
2. 保留可复用的发布脚本（`b-Code/Publish-OneHistoryModule.ps1`），由宿主
   `vulcan.release.cycle` 拉起。
3. 通过 `diana.project.manifest/docs/align` 为 Janus、Mercury、Minerva、Vulcan 提供统一开发对齐入口。

### 边界

- 不提供 UI 页面，不注册窗口，不参与用户日常交互。
- 不登记 `diana.worktree.*`、`diana.release.*`、`diana.trial.*`。
- 消费文档权威源永远在各自仓库的 `b-Office/package/`；已发布正文位于
  `z-Publish/HistoryX-vX.Y.Z/docs/`。跨项目读取必须先执行 `diana.docs.catalog`。
- 唯一写命令是 `diana.relay.call`。
- 模块主线不是 AI 日常编辑区；工作区由宿主 `vulcan.worktree.*` 管理。Diana 自身主线修改是例外。

## 状态

| 状态 | 内容 |

## 主要交付物

| 交付物 | 权威位置 | 完成判据 |
| --- | --- | --- |
| 模块产物 | `z-Publish/HistoryDiana-vX.Y.Z/` | dll + xml + manifest + SHA256SUMS |
| 项目合同 | `b-Office-Diana/current/` | 四份现行文档与实现一致 |
| 集中发布脚本 | 宿主 `eng/pipeline/Publish-OneHistoryModule.ps1` | 由 `vulcan.release.cycle` 调用 |
| z 文档查看器 | `diana.docs.catalog` 与 `diana.docs.<域>` | catalog 文本必须出现在对话中 |

## 依赖

- **HistoryVulcan 宿主**：最低 `4.6.0`；提供命令注册、MCP 投影、工作区与发布管线。
- **.NET SDK 9.0.315**，目标框架 `net8.0-windows`。

## 与其他项目的关系

Diana 的巡检与文档指令只读；`relay.call` 是显式写能力。
别的项目通过 Diana MCP 读取正式 z 文档通道；开发闭环走宿主 MCP。
