# HistoryDiana 现行约定

本仓唯一的长期文档。这里只写**从代码和测试里看不出来的项目元数据**；做法以代码为准，
每版做了什么看 `git log`。条目被推翻就直接改掉，不留历史。

## 真相在哪

| 要知道的 | 去哪看 |
| --- | --- |
| `diana.*` 指令怎么调用 | 注册自描述：`diana.docs.read domain=diana`；改指令后 `diana.docs.audit domain=diana` 零缺陷 |
| 别的模块怎么调用 | 先 `diana.docs.catalog`，再 `diana.docs.read domain=<域>`。不要打开邻接仓的文档 |
| 代码面（`HistoryDiana.dll`） | 随包的 `HistoryDiana.xml`；公开类型缺 summary 由 Smoke 拦 |
| 行为是否成立 | `b-Code-HistoryDiana/tests/HistoryDiana.Smoke`，测试注释写着每条规矩为什么存在 |
| 版本与宿主下限 | `b-Code-HistoryDiana/HistoryDianaVersion.props`（`HistoryDianaVersion` 与 `MinimumHistoryVulcanVersion`） |
| 已授权项目自己的现行文档 | `diana.project.docs`。这是维护入口，不代替上面的指令说明书 |

## 取舍

- **Diana 是 AI 工具区，不是 AI 工作区。** 面向 AI、跨项目、又不属于业务领域的工具默认归这里。业务模块仍拥有自己的领域命令，Diana 只发现和中继，不复制实现。「AI 工作区」只指 `F:\ai工作区` 下由开发管线创建的临时 Git worktree。
- **没有自己的界面。** `module.manifest.json` 的 `ui` 恒为 `false`。`diana.view.*` 只观察已经在跑的 HistoryVulcan 前端，不注册窗口，也不为截图把最小化的窗口还原。
- **开发管线不在本模块。** 冻结的 `vulcan.dev.start` / `submit` / `finish` 只走宿主 Console CLI，不投影到 MCP，也不得经 `diana.relay.call` 绕行。`diana.host.*` 只转发装载状态，不安装、不重载。
- **写命令只有两条。** `diana.relay.call` 调用当前 MCP 工具；`diana.view.capture` 只把 PNG 写进宿主数据目录下的 `captures`。其余全部只读。
- **项目文档读 manifest 里声明的那一份。** 改造完的仓只有 `documents.conventions`；还没改的仍是 `overview` / `technicalContract` / `decisions` / `verification`。省略 `kind` 时，有 `conventions` 就读它，否则读 `overview`。不接受任意路径。

## 真机才知道的

- **`diana.host.observe` 不是 submit 的成功回执。** 它是分次快照（`atomic=false`），`pipeline.status` 恒为 `unavailable`。装没装上以 Console CLI 回执为准，再核对目标 `instanceId` 已变、Aurora 的 `commandCount` 不为 0。
- **`issues` 是证据缺不缺，`errorCount` 才是错误条数。** `issues` 为空时仍可能有错误。`logsComplete=false` 时用 `diana.log.read` 的 `nextAfter` 接着翻，不要换一块新基线把漏掉的错误跳过去。
- **生效的是已安装的运行包，不是已提交的源码。** 热装没接上时，命令面仍是上一份。

## 工程约定

- 发版改三处版本号：`HistoryDianaVersion.props` 的 `HistoryDianaVersion`、`module.manifest.json`、`project.manifest.json`。漏改 `module.manifest` 时宿主静默跳过整个模块。
- 最低宿主 HistoryVulcan 6.0.0。项目库根问 `vulcan.host.info`，MCP 地址问 `portunus.mcp.status`；`HISTORYCLIO_ROOT` / `HISTORYVULCAN_ENDPOINT` 只作测试与排障覆盖。
- 生产源码在 `b-Code-HistoryDiana`，Smoke 在其下 `tests/HistoryDiana.Smoke`，不得嵌回生产目录。项目合同在 `b-Code/Test-ProjectContract.ps1`。
- 本仓文档根是 `b-Office-Diana/`，不是 `b-Office/`。长期文档只留 `current/现行约定.md`。
- 发布描述在根 `project.manifest.json` 的 `publish` 节。候选由 `vulcan.dev.submit` 构建并热装，本仓不自行发布。
- 不留 `history/`、方案、需求书。仍有效的结论写进本文、调用处注释或 Smoke。
