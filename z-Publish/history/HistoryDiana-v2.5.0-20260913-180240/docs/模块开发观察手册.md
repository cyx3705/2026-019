# HistoryDiana 模块开发观察手册

面向**正在开发任一 OneHistory 模块的 AI**。Diana 是 AI 工具区，本手册只讲一件事：
一轮模块开发里，什么时候用 Diana 的哪条命令，拿到什么可复核的证据。

**流程不在这里。** 开工作区、送审、并回主线以 HistoryVulcan
`b-Office/package/模块开发手册.md` 为准（`diana.docs.read domain=vulcan file=docs/模块开发手册.md heading=<章节>`）。
Diana 不拥有 `vulcan.dev.start` / `submit` / `finish`，那三条只走 Console CLI，不进 MCP，
也不得经 `diana.relay.call` 绕行。本手册只补上「怎么看」，不改「怎么走」。

## Diana 在一轮里出现在三处

| 时机 | 做什么 | 命令 |
| --- | --- | --- |
| 改代码之前 | 取基线，后面才有东西可比 | `diana.log.read limit=1`、`diana.host.modules name=<模块>`、改界面时加 `diana.view.capture` |
| `submit` 成功之后 | 核对宿主手册第四节的判据 | `diana.host.ready`、`diana.host.modules`、`diana.log.read after=<基线>`、`diana.view.capture` |
| 卡住时 | 先定位再动手 | 见下文「症状对照」 |

## 一、改之前先取基线

三条，都是只读，合起来不到一秒：

```text
diana.log.read limit=1
diana.host.modules name=HistoryMercury
diana.view.capture                      # 只有要改界面时才需要
```

要留在对话里的三个值：

- `nextAfter`：控制台当前最大序号。这一轮之后的错误就是「大于它的那些」。
- `frontendInstanceId`：前端实例身份。**它变了说明前端重启过，旧的 `after` 立刻作废**，
  改用 `since=<ISO 时间>` 重新划线，不要跨实例复用序号。
- 目标模块当前的 `instanceId` 与 `version`：热重载是否真的发生，就靠它和事后那个比。

改界面还要留 PNG 的绝对路径、`Width`/`Height`、`Sha256`。**只记路径不算取证**：
Diana 返回的是文件，不是图像，AI 必须真的把 PNG 读进来看。

## 二、`submit` 之后按判据核对

宿主手册第四节的成功判据有三条：回执含「已热重载到活宿主」、该模块 `instanceId` 已变、
其它模块（尤其 Aurora）的 `commandCount` 不得变成 0。第一条看 CLI 回执，后两条用 Diana：

```text
diana.host.ready                         # false 就是还在装，等一下重查
diana.host.modules name=HistoryMercury   # instanceId 与基线不同 = 真的重载了
diana.host.modules                       # 看全表：Aurora 的 commandCount 必须 > 0
diana.log.read after=<基线 nextAfter> minlevel=error
```

判读要点：

- **同版本覆盖时版本字符串可以不变**，`instanceId` 变了就是成功，不要误报失败。
- `diana.host.ready` 返回 false 不等于失败，只说明本轮装载还没接完；重查，别据此回滚。
- `attachFailures` 非空 = 该模块装进去了但 `Attach` 抛了异常。**原文就在返回里**，
  这正是「桌面上 UI 消失但命令还在」那一类故障的直接证据，不必去翻宿主日志。
- `diana.log.read` 只覆盖 **Aurora 前端控制台的内存缓冲**：前端自己的异常、命令执行结果都在，
  宿主进程侧的模块装载日志**不在**。装载问题看 `diana.host.modules` 的 `attachFailures`，
  不要指望 `log.read` 里能搜到。
- `truncated=true` 只表示**本次结果不完整**，可能是 `limit` 截断，也可能是 256 KiB 上限。
  对比 `matchedCount` 与 `returnedCount` 就能分辨：不相等就是 `limit` 卡住了，加大 `limit`
  或用 `after` 翻页，别当成日志出错。

改了界面再补一次视觉核对：

```text
diana.view.windows                       # 确认句柄，别抓错窗口
diana.view.capture handle=0x2031A
```

拿到新 PNG 后**实际读取图像**，和基线那张比布局、文字、重叠和空白。两次 `Sha256` 完全相同
= 客户区一个像素都没变，这本身就是结论（改动没生效，或者改的地方不在这个窗口）。

## 三、症状对照

| 症状 | 先用哪条 | 判据 |
| --- | --- | --- |
| 重载后模块没出现 | `diana.host.modules` | 全表里有没有它；有则看 `attached` 与 `attachFailures` |
| 命令还在但界面没了 | `diana.host.modules name=<模块>` | `attachFailures` 原文；`ui=true` 却 `attached=false` |
| 装载像是没做完 | `diana.host.ready` | false = 仍在装；true 后再判其它 |
| Aurora 指令数变成 0 | `diana.host.modules` | Aurora 那行 `commandCount`；为 0 交给人，不要自己重载宿主 |
| 前端报错但不知道原文 | `diana.log.read after=<基线> minlevel=error` | 多行异常和堆栈原样返回，不要截图去认字 |
| 只想确认界面长什么样 | `diana.view.windows` → `capture` | 后台捕获，不移动鼠标、不抢前台 |
| 不确定别的模块暴露了什么 | `diana.docs.catalog` → `diana.docs.read` | 只读各仓已发布的 z 正文，不打开邻接源码树 |

**禁止**：为只读观察调用 Computer Use、点击窗口、移动鼠标或抢前台。确实需要点击、输入、
拖拽时，先取得用户明确同意。

## 四、Diana 不做什么

- 不开工作区、不提交、不发布、不装模块。`vulcan.dev.*` 与 `vulcan.module.install` 归宿主，
  只走 Console CLI。`diana.host.*` 只读装载状态，不改运行包。
- 不读 `%AppData%` 下的 `shell-*.log`，不做 OCR、不碰 UI 自动化树、不激活窗口。
- 不保存别的模块的文档副本；正文永远在各仓 `z-Publish/HistoryX-vX.Y.Z/docs/`。
- 不轮询、不订阅流。每条命令只给一个有界快照。

## 五、Diana 工具不可用时

先把**具体原因**写进对话（工具表里没有 Diana、调用超时、鉴权失败），再降级，不要静默换路子：

- `diana.host.*` 不可用 → `HistoryVulcan.Cli.exe --runtime "vulcan.module.list" --format json`，
  读 `data` 或 `runtimeAck.modules`，不是 `moduleInstanceIds`。
- `diana.docs.*` 不可用 → 只读目标项目正式 `z-Publish/.../docs`，不得转去扫邻接源码树。
- `diana.view.*` 不可用 → 记录原因；**不得**因此改用 GUI 控制。
- `diana.log.read` 不可用 → 多半是 Aurora 未装载或正在热重载；先 `diana.host.ready`，
  不要退回去读磁盘日志冒充控制台。

## 命令速查

| 命令 | 只读 | 用途 |
| --- | --- | --- |
| `diana.host.modules [name=]` | 是 | 活宿主装载的模块、版本、`instanceId`、指令数、`attachFailures` |
| `diana.host.ready` | 是 | 本轮模块装载是否已全部接上宿主 |
| `diana.log.read [minlevel= source= keyword= since= after= limit=]` | 是 | 当前前端控制台内存日志，默认只给 Error 及以上 |
| `diana.view.windows` | 是 | 可捕获的 HistoryVulcan 前端窗口与句柄 |
| `diana.view.capture [handle=]` | 否 | 原尺寸客户区 PNG，写入 Diana 运行态截图目录 |
| `diana.docs.catalog` / `diana.docs.read domain= [file= heading=]` | 是 | 各仓已发布说明书 |
| `diana.relay.list` / `describe` / `call` | `call` 为写 | 当前 MCP 工具目录与调用 |
